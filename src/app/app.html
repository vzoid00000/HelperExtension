    Sprachmodell
    
                  
    Für Relevanzprüfung, Tagging und – je nach Einstellung – Übersetzung.
    
                
    
                
    
                  
    
                    
                    
    Für PCs, auf denen nichts installiert werden darf: Claude API mit Haiku 5.5 (grob 10–40 Cent pro Arbeitstag). Danach API-Key eintragen und speichern.
    
                  
    
                  
    
                    
                    
    Abo-Kontingent statt API-Key; braucht Node.js und Claude Code auf diesem PC (http://localhost:4310/v1, Modell opus).
    
                  
    
                  
    
                  
    
                    
                    
                  
    
                  
    
                    
                    
                    
    Erstellen unter console.anthropic.com → API Keys (Guthaben vorab laden, mindestens 5 $). Wird nur lokal in dieser Extension gespeichert.
    
                  
    
                  
    
                    
                    
                    
    Grobe Schätzung für rund zehn Meldungen am Tag; der Tag-Katalog wird zwischengespeichert.
    
                  
    
                
    
              
    

              
              
    
                
    
                  
    Übersetzung
    
                  
    Titel und Artikeltext werden wortgetreu EN → DE übersetzt – nichts wird ergänzt oder gekürzt.

Free-Keys enden auf „:fx“ und nutzen automatisch den Free-Endpunkt.
